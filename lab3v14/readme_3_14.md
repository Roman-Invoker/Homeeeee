## 🚀 Інструкція із запуску

### Попередні вимоги
Переконайтеся, що у вашій системі встановлено необхідний компілятор або інтерпретатор:

```bash
# Перевірка компілятора C++
g++ --version

# Або перевірка Python
python --version
```

### Інструкція зі збірки та запуску

1. **Клонуйте репозиторій або завантажте файли:**
   ```bash
   git clone <посилання-на-репозиторій>
   cd <назва-папки>
   ```

2. **Компіляція (для C++ / C):**
   ```bash
   g++ -Wall -Wextra src/*.cpp -o lab3_v14
   ```

3. **Запуск програми:**
   ```bash
   # Для C / C++:
   ./lab3_v14

   # Для Python:
   python src/main.py
   ```
